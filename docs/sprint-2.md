# Sprint 2: бекенд-обсяг

Спринт 24.11–08.12.2026, проєкт IXMD «Стиляги». Ціль: замовник оформлює пілотний зразок зі знижкою, повторний запит не створює друге замовлення.

## Історії

| Ключ | Історія | SP | Бекенд-обсяг |
|---|---|---|---|
| IXMD-65 | US11 Пілотний зразок | 4.5 | прапорець `is_pilot`, фіксована кількість 1, розрахунок ціни |
| IXMD-66 | US12 Шкала знижок | 3.0 | межі 10 і 50 шт, 5 % і 10 %, перерахунок при зміні кількості |
| IXMD-67 | NFR-07 Ідемпотентність | 7.5 | `idempotency_key`, 409 на повтор, ключ у логах |

## Правила

1. Одна гілка на задачу: `feature/IXMD-<номер>-<опис>`.
2. PR у `main` лише зі зеленим `check` і одним схваленням.
3. Commit messages за Conventional Commits.
4. Кожен PR менший за 400 рядків.
5. Після merge деплой на Cloudflare Worker і перевірка `/health`.

## Definition of Done

- `bun run check` зелений.
- Контракт з `contract/openapi.yaml` не змінений або змінений через тег `contract-vX.Y.Z`.
- Помилки у спільному форматі `{ error: { code, requestId } }`.
- Немає секретів у коді й логах.
